# فَصْل | FASL

بوت قصص تفاعلية على Telegram يعمل عبر **Cloudflare Workers + D1** دون خادم دائم.

## الوظائف الحالية
- مكتبة قصص تُعرض بأزرار، مع دعم تحميل قصص إضافية من جدول D1.
- جلسة مستقلة لكل محادثة، مع منع تداخل جلسات القصة في المحادثة نفسها.
- الخاص: اختيارات مباشرة بأزرار Inline.
- المجموعات: ينشر المشهد أولًا، ثم يفتح التصويت بعد مهلة افتراضية 120 ثانية. التصويت نفسه يغلق تلقائيًا بعد 120 ثانية، ثم يعتمد البوت أعلى الأصوات.
- معالجة التعادل بمسار مشترك محدد في القصة، أو إعادة التصويت عند تعادل مسارات مختلفة بدل اختيار مسار عشوائي أو إنهاء الجلسة.
- إيقاف الجلسة، إحصاءات المالك، إذاعة للرسائل، تفعيل/إيقاف القصص، تقييم من 1 إلى 5، منع تكرار تحديثات Telegram، وحماية webhook بـ secret token.
- تذكير الجمعة اختياري.

## متطلبات
- حساب Cloudflare.
- Telegram bot token من @BotFather.
- GitHub repository مربوط بـ Cloudflare أو Wrangler CLI.
- Node.js 20+ عند النشر عبر CLI.

## إعداد Cloudflare
1. أنشئ D1 باسم `fasl-db`.
2. انسخ `database_id` الحقيقي إلى `wrangler.toml` بدل `REPLACE_WITH_D1_DATABASE_ID`.
3. نفّذ `npm install`.
4. نفّذ `npx wrangler d1 execute fasl-db --remote --file=./schema.sql`.
5. عند تحديث قاعدة موجودة، نفّذ ترحيل دفتر الأدلة: `npx wrangler d1 execute fasl-db --remote --file=./migrations/0002_session_clues.sql`.
6. نفّذ ترحيل الاستجوابات: `npx wrangler d1 execute fasl-db --remote --file=./migrations/0003_session_interrogations.sql`.
5. أضف الأسرار:
   - `npx wrangler secret put BOT_TOKEN`
   - `npx wrangler secret put WEBHOOK_SECRET` (قيمة عشوائية طويلة، أحرف وأرقام وشرطة فقط)
   - `npx wrangler secret put ADMIN_IDS` (رقم Telegram ID للمالك؛ يمكن إضافة أكثر من ID بفواصل)
6. انشر محليًا: `npm run deploy`.

### النشر من GitHub Actions
أُضيف سير عمل نشر يدوي باسم **Deploy FASL to Cloudflare**. قبل تشغيله:
1. أنشئ Cloudflare API Token بصلاحية **Workers Editor** على Worker `fasl` الموجود.
2. أضف في GitHub Repository → Settings → Secrets and variables → Actions السرّين:
   - `CLOUDFLARE_API_TOKEN`
   - `CLOUDFLARE_ACCOUNT_ID`
3. افتح Actions، واختر **Deploy FASL to Cloudflare**، ثم **Run workflow**.

سير العمل يشغّل `npm test` أولًا، ولا ينشر إذا فشلت الاختبارات أو غابت بيانات الاعتماد. النشر يدوي ولا يحدث تلقائيًا مع كل Push. لا تحتاج صلاحيات D1 منفصلة لمجرد نشر Worker مرتبط بقاعدة D1؛ صلاحيات القاعدة مطلوبة فقط عند تنفيذ عمليات مباشرة عليها.

بعد نشر Worker، سيزامن `ensureSeed` محتوى القصص الجديدة إلى D1 عند أول تحديث Telegram، وسيعطّل قصة `the-empty-ship` المتقاعدة دون حذف بياناتها.
7. سجّل webhook بعد استبدال القيم:
```bash
curl -X POST "https://api.telegram.org/bot< BOT_TOKEN >/setWebhook" \
  -d "url=https://<WORKER_SUBDOMAIN>.workers.dev/webhook" \
  -d "secret_token=<WEBHOOK_SECRET>" \
  -d 'allowed_updates=["message","callback_query","poll"]'
```
احذف المسافات داخل `<BOT_TOKEN>` عند الاستبدال. لا تشارك التوكن أو السر مع أي شخص.

## ملاحظات تشغيل مهمة
- Cron مضبوط كل دقيقة؛ لذلك مهلة بدء تصويت المجموعة هي **120 ثانية كموعد مستهدف** وقد يتأخر تنفيذها حتى دورة Cron التالية (بحد أقصى يقارب دقيقة إضافية). إغلاق التصويت نفسه مضبوط من Telegram على 120 ثانية.
- تذكير الجمعة مضبوط حاليًا عند 09:00 UTC (11:00 صباحًا بتوقيت مصر الشتوي/12:00 صيفًا)، ويُرسل مرة واحدة في اليوم لكل المحادثات المسجلة. اضبط التوقيت حسب احتياجك.
- القصة المرفقة نموذج أولي قصصي، وليست بعد مكتبة كبيرة أو ضمانًا موثقًا لمدة 12–20 دقيقة. يجب اختبار زمن القراءة والاختيارات مع لاعبين حقيقيين قبل الإعلان عن المدة.
- لوحة المالك الحالية تعرض إحصاءات أولية فقط؛ أدوات إدارة القصص والإذاعة وجدولة التذكير لكل مجموعة ضمن مرحلة لاحقة.
- لا يوجد أي توكن أو سر داخل المستودع.

## بنية الملفات
- `src/index.ts`: webhook، أوامر Telegram، جلسات القصص والاختبارات، التصويت، cron.
- `src/stories.ts`: تسجيل القصص الأساسية.
- `src/extra-stories.ts`: القصص الإضافية المتفرعة.
- `schema.sql`: جداول D1 والفهارس.
- `scripts/validate-assessments.mjs`: فحص محتوى الاختبارات ونتائجها، بما فيها بنية IPIP-50 والتصحيح العكسي.
- `EDITORIAL_STANDARD.md`: بوابة المراجعة التحريرية وحقوق المصادر والاختبارات.
- `wrangler.toml`: إعدادات Worker وD1 وCron.

## مكتبة القصص والأقسام

تُفتح المكتبة على أقسام، ثم تظهر القصص المتاحة داخل القسم المختار. أُزيلت القصص القصيرة الخطية التي لا تمنح اللاعب قرارات ذات أثر كافٍ؛ لا تُعرض قصة لمجرد ملء القسم.

- **التحقيق في القضايا:** النداء 03:17.
- **الرعب والغموض:** كلب المستنقع.
- **الغموض والتشويق:** الرصيف الأخير، الدقّتان الأخيرتان.
- **المغامرات والاستكشاف:** الطريق الذي لا يظهر.
- **النجاة والكوارث:** الإشارة البيضاء.
- **الخيال العلمي:** النسخة التي لم تتكلم.
- **الأدب والدراما:** المقعد رقم سبعة.
- **القصص الواقعية والتاريخية:** ملف الممر 1959.

**الإشارة البيضاء** قصة نجاة وتحقيق متفرعة في محطة أرصاد جبلية معزولة، تتطلب مقارنة الإشارات والسجلات قبل اتخاذ قرار الإنقاذ.

**النسخة التي لم تتكلم** خيال علمي قريب عن أرشيف صوتي وحقوق الموافقة والهوية الرقمية.

**المقعد رقم سبعة** دراما أدبية عن ذاكرة بلدة ورسائل محفوظة وشهادات لم تدخل السجلات الرسمية.

**الدقّتان الأخيرتان** لغز أصلي في مسرح قديم على وشك الهدم. يبدأ بصوت جرس مستحيل، ثم يتحول إلى تحقيق في مخطط محذوف ووثائق ملكية وتقرير حريق متلاعب به. يستلهم مبدأ الدليل الذي يغفله الجميع من تقاليد التحقيق الكلاسيكي، مع مرجع أدبي معلن إلى قصة إدغار آلان بو *The Purloined Letter*؛ ولا يقتبس حبكتها أو شخصياتها.

**ملف الممر 1959** تحقيق تفاعلي مستوحى من حادثة ممر دياتلوف الحقيقية. تميز القصة بين الوقائع المنشورة والفرضيات، وتعرض نموذج الانهيار الثلجي بوصفه تفسيرًا علميًا محتملًا لا حقيقة نهائية. مراجعها:
- [الدراسة العلمية في Nature](https://www.nature.com/articles/s43247-020-00081-8)
- [شرح EPFL](https://longread.epfl.ch/en/dossier/quand-la-science-permet-dexplorer-un-mystere-russe-vieux-de-60-ans)
- [فيديو BBC عن الحادثة](https://www.youtube.com/watch?v=NiV-yv95jKg)

**كلب المستنقع** قصة أصلية تستلهم أجواء الأدب القوطي والتحقيق الكلاسيكي، مع الإشارة إلى رواية *The Hound of the Baskervilles* المتاحة ضمن [Project Gutenberg](https://www.gutenberg.org/ebooks/2852). القصة ليست نسخًا للرواية ولا إعادة لحبكتها.

تظهر ملاحظة المصدر قبل بدء القصص المستندة إلى مصادر، وتُعرض روابط المراجع بعد النهاية. لا يظهر تقرير أدلة أو وقت افتراضي في نهاية قصة لا تتبع الأدلة أو الوقت فعلًا. لا تُنسخ نصوص فيديوهات أو روايات محمية؛ تُستخدم الوقائع الموثقة أو الأعمال المتاحة قانونيًا لبناء صياغة تفاعلية أصلية.

تدعم الاختيارات صورة توضيحية مستقلة لكل خيار. في الخاص تظهر صورة كل خيار مع زر اختياره، وفي المجموعات تظهر صور الخيارات قبل استطلاع Telegram.

## تنويع السرد ومنع الملل
- القصص الجديدة تستخدم أدلة مترابطة، وشهادات قد تتعارض، وتوقيتًا زائفًا، وقرائن علمية؛ لا تُكشف الإجابة من أول مشهد.
- مسارات متعددة ونهايات مختلفة، مع نقاط التقاء حتى لا تنقطع القصة عند كل اختيار.
- الاختيارات تستطيع تسجيل أدلة وقرارات دائمة داخل الجلسة، وفتح خيارات لاحقة أو إخفاء خيارات لم يعد من المنطقي ظهورها؛ ويُطبّق ذلك في الخاص وتصويت المجموعات.
- قصص النجاة تكافئ التفكير الهادئ وإدارة الموارد، وقصص المغامرة تكافئ الاستكشاف وربط الإشارات.
- الأعمال الواقعية تفصل الوقائع الموثقة عن الفرضيات والتخييل الدرامي، وتعرض المصادر للاعب. لا تُحوّل الاستنتاجات المحتملة إلى حقائق مؤكدة.
- صور توضيحية مرتبطة بالاختيارات لزيادة الإحساس بالمشهد.
- التحقيقات تدعم دفتر أدلة محفوظًا لكل جلسة، وجمع القرائن تلقائيًا، واستجواب المشتبه بهم، ومواجهة الأقوال بالأدلة، وتتبع التناقضات. لا يُقبل الاتهام قبل جمع الحد الأدنى من الأدلة وإجراء استجوابات كافية، ويمكن للمجموعة المشاركة في الاستنتاج عبر التصويت.
- تتم مزامنة محتوى القصص المحدث إلى D1 تلقائيًا دون تغيير حالة تفعيل/إيقاف القصة.
- بوابة جودة النشر ترفض أي قصة يقل عدد اختياراتها عن 18 أو لا تملك مسارين نهائيين على الأقل، إلى جانب فحص جميع روابط المشاهد والنهايات القابلة للوصول.


### النهايات المتفرعة في التحقيقات
- تُختار نهاية القضية وفق الأدلة التي جُمعت ومواجهات الاستجواب التي نُفذت، لا وفق الاتهام وحده.
- تتضمن قضية الغرفة 17 نهاية كاملة عند إغلاق جميع التناقضات، ونهاية إدانة مع بقاء الدافع غامضًا، ونهاية للحقيقة الناقصة عندما لا تكتمل سلسلة الإثبات.
- يتم تقييم شروط النهاية من سجلات الجلسة المحفوظة في D1 عند الاتهام الصحيح، في الخاص والمجموعات.


## الاختبارات | TESTS
يحتوي البوت على اختبارات خاصة بالمستخدم، وتُحفظ إجابات الجلسة مؤقتًا في جدول `settings` ثم تُحذف بعد إصدار النتيجة:
- **كيف يعمل عقلك؟** — أسلوب التفكير الغالب، مع نقاط قوة ومجالات تطوير.
- **أي شخصية تشبه في طريقة تفكيرك؟** — مقارنة ترفيهية مع نماذج خيالية، وليست تطابقًا نفسيًا.
- **أين يناسبك العمل؟** — ميول مهنية واقتراح أقسام وظيفية استرشادية.
- **اختبار القدرات والاستدلال** — أسئلة منطقية وعددية ولفظية مع تصحيح وشرح بعد الانتهاء.
- **محاكاة مواقف العمل** — مواقف حكم مهني وأولويات وتعاون مستوحاة من نماذج التقييم الوظيفي.
- **السمات الخمس الكبرى | IPIP-50** — 50 عبارة وفق مقياس IPIP Big-Five Factor Markers، مع تصحيح البنود العكسية وعرض متوسط كل بُعد. البنود الأصلية من بنك IPIP المتاح للملكية العامة؛ الصياغة العربية ترجمة عملنا ولم تُتحقق سيكومتريًا بصورة مستقلة، لذلك لا تُعرض كنسخة عربية معيارية أو تشخيصية.
- تُجرى الاختبارات في المحادثة الخاصة فقط لحماية خصوصية الإجابات.
- النتائج استرشادية ولا تمثل تشخيصًا نفسيًا أو اختبار توظيف معتمدًا، ولا ينبغي استخدامها وحدها لاتخاذ قرار توظيف. مقياس IPIP-50 يُنسب إلى Goldberg (1992)، وتُذكر حدود الترجمة العربية بوضوح للمستخدم.
- ابدأ عبر الأمر `/tests` أو زر **🧠 الاختبارات** في قائمة المكتبة.
