# فَصْل | FASL

بوت قصص تفاعلية على Telegram يعمل عبر **Cloudflare Workers + D1** دون خادم دائم.

## الوظائف الحالية
- مكتبة قصص تُعرض بأزرار، مع دعم تحميل قصص إضافية من جدول D1.
- جلسة مستقلة لكل محادثة، مع منع تداخل جلسات القصة في المحادثة نفسها.
- الخاص: اختيارات مباشرة بأزرار Inline.
- المجموعات: ينشر المشهد أولًا، ثم يفتح التصويت بعد مهلة افتراضية 120 ثانية. التصويت نفسه يغلق تلقائيًا بعد 120 ثانية، ثم يعتمد البوت أعلى الأصوات.
- معالجة التعادل بمسار مشترك محدد في القصة، أو إعادة التصويت عند تعادل مسارات مختلفة بدل اختيار مسار عشوائي أو إنهاء الجلسة.
- إيقاف الجلسة، إحصاءات المالك، إذاعة للرسائل، تفعيل/إيقاف القصص، تقييم من 1 إلى 5، منع تكرار تحديثات Telegram، وحماية webhook بـ secret token.
- تذكير الجمعة اختياري.

## متطلبات
- حساب Cloudflare.
- Telegram bot token من @BotFather.
- GitHub repository مربوط بـ Cloudflare أو Wrangler CLI.
- Node.js 20+ عند النشر عبر CLI.

## إعداد Cloudflare
1. أنشئ D1 باسم `fasl-db`.
2. انسخ `database_id` الحقيقي إلى `wrangler.toml` بدل `REPLACE_WITH_D1_DATABASE_ID`.
3. نفّذ `npm install`.
4. نفّذ `npx wrangler d1 execute fasl-db --remote --file=./schema.sql`.
5. عند تحديث قاعدة موجودة، نفّذ ترحيل دفتر الأدلة: `npx wrangler d1 execute fasl-db --remote --file=./migrations/0002_session_clues.sql`.
6. نفّذ ترحيل الاستجوابات: `npx wrangler d1 execute fasl-db --remote --file=./migrations/0003_session_interrogations.sql`.
5. أضف الأسرار:
   - `npx wrangler secret put BOT_TOKEN`
   - `npx wrangler secret put WEBHOOK_SECRET` (قيمة عشوائية طويلة، أحرف وأرقام وشرطة فقط)
   - `npx wrangler secret put ADMIN_IDS` (رقم Telegram ID للمالك؛ يمكن إضافة أكثر من ID بفواصل)
6. انشر: `npm run deploy`.
7. سجّل webhook بعد استبدال القيم:
```bash
curl -X POST "https://api.telegram.org/bot< BOT_TOKEN >/setWebhook" \
  -d "url=https://<WORKER_SUBDOMAIN>.workers.dev/webhook" \
  -d "secret_token=<WEBHOOK_SECRET>" \
  -d 'allowed_updates=["message","callback_query","poll"]'
```
احذف المسافات داخل `<BOT_TOKEN>` عند الاستبدال. لا تشارك التوكن أو السر مع أي شخص.

## ملاحظات تشغيل مهمة
- Cron مضبوط كل دقيقة؛ لذلك مهلة بدء تصويت المجموعة هي **120 ثانية كموعد مستهدف** وقد يتأخر تنفيذها حتى دورة Cron التالية (بحد أقصى يقارب دقيقة إضافية). إغلاق التصويت نفسه مضبوط من Telegram على 120 ثانية.
- تذكير الجمعة مضبوط حاليًا عند 09:00 UTC (11:00 صباحًا بتوقيت مصر الشتوي/12:00 صيفًا)، ويُرسل مرة واحدة في اليوم لكل المحادثات المسجلة. اضبط التوقيت حسب احتياجك.
- القصة المرفقة نموذج أولي قصصي، وليست بعد مكتبة كبيرة أو ضمانًا موثقًا لمدة 12–20 دقيقة. يجب اختبار زمن القراءة والاختيارات مع لاعبين حقيقيين قبل الإعلان عن المدة.
- لوحة المالك الحالية تعرض إحصاءات أولية فقط؛ أدوات إدارة القصص والإذاعة وجدولة التذكير لكل مجموعة ضمن مرحلة لاحقة.
- لا يوجد أي توكن أو سر داخل المستودع.

## بنية الملفات
- `src/index.ts`: webhook، أوامر Telegram، جلسات، التصويت، cron.
- `src/stories.ts`: محتوى القصص ومساراتها.
- `schema.sql`: جداول D1 والفهارس.
- `wrangler.toml`: إعدادات Worker وD1 وCron.

## مكتبة القصص والاختيارات المصوّرة
تتضمن المكتبة حاليًا عشر قصص:
- الرصيف الأخير — غموض وتشويق.
- الغرفة التي تتنفّس — رعب نفسي وغموض.
- رسالة من الغد — خيال علمي وتحقيق.
- مدينة بلا ظلال — مغامرة وخيال علمي.
- لغز الغرفة 17 — تحقيق جنائي، غرفة مغلقة، أدلة جنائية وشهادات متناقضة.
- 72 ساعة بلا إشارة — نجاة بعد كارثة، إدارة موارد وقرارات تحت الضغط.
- البعثة التي اختفت — مغامرة واستكشاف وألغاز أثرية.
- السفينة التي عادت وحدها — لغز بحري مستوحى من قضية السفينة التاريخية ماري سيليست عام 1872.
- النداء 03:17 — تشويق وتحقيق داخل مستشفى مغلق، مع شهادات متعارضة ومسارات تعتمد على الأدلة والذكريات.
- الطريق الذي لا يظهر — قصة نجاة صحراوية تتغير وفق الموارد والثقة والقرارات الجماعية.

تدعم الاختيارات صورة توضيحية مستقلة لكل خيار. في الخاص تظهر صورة كل خيار مع زر اختياره، وفي المجموعات تظهر صور الخيارات قبل استطلاع Telegram.


## تنويع السرد ومنع الملل
- القصص الجديدة تستخدم أدلة مترابطة، وشهادات قد تتعارض، وتوقيتًا زائفًا، وقرائن علمية؛ لا تُكشف الإجابة من أول مشهد.
- مسارات متعددة ونهايات مختلفة، مع نقاط التقاء حتى لا تنقطع القصة عند كل اختيار.
- الاختيارات تستطيع تسجيل أدلة وقرارات دائمة داخل الجلسة، وفتح خيارات لاحقة أو إخفاء خيارات لم يعد من المنطقي ظهورها؛ ويُطبّق ذلك في الخاص وتصويت المجموعات.
- قصص النجاة تكافئ التفكير الهادئ وإدارة الموارد، وقصص المغامرة تكافئ الاستكشاف وربط الإشارات.
- الأعمال التاريخية مستوحاة من وقائع عامة، ثم تُحوّل إلى حبكات وشخصيات خيالية؛ ليست إعادة سرد حرفية لملفات القضايا.
- صور توضيحية مرتبطة بالاختيارات لزيادة الإحساس بالمشهد.
- التحقيقات تدعم دفتر أدلة محفوظًا لكل جلسة، وجمع القرائن تلقائيًا، واستجواب المشتبه بهم، ومواجهة الأقوال بالأدلة، وتتبع التناقضات. لا يُقبل الاتهام قبل جمع الحد الأدنى من الأدلة وإجراء استجوابات كافية، ويمكن للمجموعة المشاركة في الاستنتاج عبر التصويت.
- تتم مزامنة محتوى القصص المحدث إلى D1 تلقائيًا دون تغيير حالة تفعيل/إيقاف القصة.


### النهايات المتفرعة في التحقيقات
- تُختار نهاية القضية وفق الأدلة التي جُمعت ومواجهات الاستجواب التي نُفذت، لا وفق الاتهام وحده.
- تتضمن قضية الغرفة 17 نهاية كاملة عند إغلاق جميع التناقضات، ونهاية إدانة مع بقاء الدافع غامضًا، ونهاية للحقيقة الناقصة عندما لا تكتمل سلسلة الإثبات.
- يتم تقييم شروط النهاية من سجلات الجلسة المحفوظة في D1 عند الاتهام الصحيح، في الخاص والمجموعات.
